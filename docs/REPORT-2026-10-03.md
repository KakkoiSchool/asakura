## Found along the way (not changed: game code is Asakura-san's)
These are worth passing to Asakura-san. None of them blocks publishing.
1. **Phones see only the middle of the court.** `#game-container` is a fixed
   800x600 box, so on a 390px-wide phone it overflows on both sides. The left
   overflow cannot be scrolled to, so the left goal and the player's starting
   spot are always off screen. A CSS fix in `index.html` (let the box and the
   canvas shrink to the screen width, keeping the 4:3 shape) would solve it.
2. **Dragging on a phone moves the page, not the paddle.** The canvas has no
   `touch-action: none`, so the browser takes the gesture after about two
   moves (`pointercancel`) and pans the page instead (measured: 170px).
   `main.js` clears the pointer only on `pointerup`, so after that cancel the
   paddle stays parked where the finger was and the pointer dot stays drawn
   until the next tap. Fix: `touch-action: none` on the canvas, and treat
   `pointercancel` like `pointerup`.
3. **Keys are case-sensitive.** Movement checks `'a'`, `'d'`, `'w'`, `'s'`
   only, so WASD does nothing with Caps Lock or Shift held. Arrow keys
   always work.
4. There is no favicon, hence the one 404 above. Harmless.
